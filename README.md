# 💱 Conversor de Moedas

Um site simples e intuitivo para conversão de moedas em tempo real, desenvolvido com HTML, CSS e JavaScript puro.

## 📋 Sobre o Projeto

O **Conversor de Moedas** é uma aplicação web que permite converter valores entre diferentes moedas internacionais de forma rápida e prática. As taxas de câmbio são buscadas em tempo real, garantindo que o resultado seja sempre atualizado.

## ✨ Funcionalidades

- 🔄 Conversão entre 10 moedas internacionais
- 📡 Taxas de câmbio atualizadas em tempo real
- 💡 Interface limpa e responsiva
- ⏳ Indicador de carregamento enquanto a cotação é buscada
- ❌ Tratamento de erros na busca das taxas

- **HTML5** — Estrutura da página
- **CSS3** — Estilização e responsividade

```
Site_Conversor_Moedas/
```

## 🚀 Como Usar

1. Clone o repositório:
   ```bash
   git clone https://github.com/Luiz-Miguel-Pimenta/Site_Conversor_Moedas.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd Site_Conversor_Moedas
   ```

3. Abra o arquivo `index.html` no seu navegador — não é necessário nenhum servidor ou instalação adicional.

## 🖥️ Como Utilizar a Interface

1. Digite o **valor** que deseja converter no campo "Valor"
2. Selecione a **moeda de origem** no campo "De"
3. Selecione a **moeda de destino** no segundo campo
4. Clique em **💲 Converter Moeda**
5. O resultado aparecerá no campo "Resultado"
